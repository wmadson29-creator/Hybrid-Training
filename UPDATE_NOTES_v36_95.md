# Hybrid Training v36.95 — Integrated Systems Audit

- Research-audited how recovery, conditioning, strength, speed/power, bodyweight/energy context, scheduling, and optional secondary work interact.
- Added a smooth concurrent-training spacing model: same-session/very-close endurance + resistance receives the greatest interference concern; separation progressively reduces it; sequence remains only a modest modifier.
- Added a small domain-specific acute-sleep modifier on top of (not instead of) integrated recovery. Speed/power and hard intermittent work are more sensitive than easy aerobic work; sleep alone never auto-rests the day.
- Added a conservative multi-signal fueling/low-energy Watch that suppresses optional add-on volume before it can alter primary training. Bodyweight loss alone cannot trigger the guard.
- Removed generic `morning + fasted => favor conditioning` and generic `late day => penalize demanding resistance/SE` score biases. Time/fed state can still learn a small personal effect after repeated direct performance evidence.
- Expanded research provenance for fasted/fed performance, carbohydrate support, time-of-day, evening exercise/sleep, endurance intensity distribution, hydration, ACWR limitations, failure recovery, and running economy.
- Intentionally retained HRV/wearables as confidence-weighted inputs rather than hard controllers; retained intensity distribution as context rather than a rigid 80/20 quota; retained stress budgets without ACWR injury prediction.
- Preserves the v36.94 Clean Technical UI, existing calendar styling, and readability improvements.
