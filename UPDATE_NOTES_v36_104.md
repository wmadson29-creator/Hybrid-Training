# Hybrid Training v36.104 — Exercise Effort Granularity

- Added **Too easy** as a distinct per-exercise effort category.
- Too easy is modeled below ordinary Easy, so clearly underloaded work provides a stronger progression/calibration signal.
- Existing categories remain: Easy, Comfortable, Challenging, Very hard, Max / failed, and Not sure.
- Legacy labels remain normalized for compatibility.
- Includes all v36.103 deployment/reload protections and Assisted Dip Machine 10-lb increment handling.
